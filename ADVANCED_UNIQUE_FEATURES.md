**Why it's unique:**

- Personalized risk scores
- Actionable prevention plans

**Implementation:**
```typescript
model HealthRiskPrediction {
  id              String   @id @default(cuid())
  userId          String
  riskType        String   // "DIABETES", "HEART_DISEASE", "HYPERTENSION"

  timeframe       String   // "6_MONTHS", "12_MONTHS", "24_MONTHS"
  factors         Json     // Contributing factors
  preventionPlan  Json     // Personalized prevention steps
  confidence      Float    // Model confidence
  createdAt       DateTime @default(now())

  actualOutcome   String?  // Track accuracy
}
```
