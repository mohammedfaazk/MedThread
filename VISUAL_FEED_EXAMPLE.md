## 🎨 Badge Design

### 🔴 URGENT Badge (HIGH Priority)
```
┌─────────────────────────────────┐
│ 🔴 ⚠️ URGENT (95)               │
│ Red background, red text        │
│ Border: red                     │
└─────────────────────────────────┘
```

### 🟡 MODERATE Badge (MEDIUM Priority)
```
┌─────────────────────────────────┐
│ 🟡 📈 MODERATE (55)             │
│ Yellow background, yellow text  │
│ Border: yellow                  │
└─────────────────────────────────┘
```

### 🟢 ROUTINE Badge (LOW Priority)
```
┌─────────────────────────────────┐
│ 🟢 ✓ ROUTINE (30)               │
│ Green background, green text    │
│ Border: green                   │
└─────────────────────────────────┘
```

## 📊 Priority Distribution

```
Feed Composition:
├── 🔴 URGENT (2 posts) ─────────── 20%
├── 🟡 MODERATE (3 posts) ────────── 30%
└── 🟢 ROUTINE (5 posts) ─────────── 50%

Sorting Order:
1. Urgency Score (Highest to Lowest)
2. Created Date (Newest to Oldest)
```

### Priority Badge Location:
```
┌─────────────────────────────────────────────────────────────┐
│ Post Header (author, time, community)                       │
│                                                             │
│ ┌─────────────────────────────────┐                        │
│ │ 🔴 URGENT (95)                  │ ← Priority Badge       │

│                                                             │

│ Post Content Preview...                                     │
│                                                             │
│ Actions (Comments, Award, Share, Save)                      │

```

### Badge Components:
```
🔴 URGENT (95)
│   │      │
│   │      └─ Urgency Score (0-100)
│   └──────── Priority Label (URGENT/MODERATE/ROUTINE)
└──────────── Emoji Indicator (🔴/🟡/🟢)
```

## 🎯 User Experience

### What Users See:
1. **Immediate Visual Hierarchy:** Color-coded badges make priority obvious
2. **Urgent Posts First:** Critical health issues always at the top
3. **Score Transparency:** Urgency score visible for context
4. **Consistent Design:** Same badge style for all post types
5. **Clear Sorting:** Posts naturally flow from urgent to routine

### Benefits:
- ✅ Quick identification of urgent content
- ✅ Better content prioritization
- ✅ Improved response times for emergencies
- ✅ Clear visual feedback on post importance
- ✅ Unified experience across all post types
